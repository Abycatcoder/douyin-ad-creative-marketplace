# 抖音广告素材工坊 V0

包版本：0.2.0。名称保留douyin-ad-creative-v0。

输入商品图片和概括信息，依次分析受众场景、设计广告创意类型与节奏、编写标准分镜、导出逐镜视频提示词，再按实际可用的媒体能力制作素材。

- 5种结构：问题解决、场景微剧情、细节揭秘、场景搭配蒙太奇、使用演示。
- 4种节奏：快节奏冲击、递进种草、微剧情、舒缓质感。
- 分镜九列：镜号、场景、景别、镜头运动方式、画面内容、声音、音乐、音响、文字标语。
- 补充时间线、动作起止、商品一致性锚点及独立的视频提示词，避免脚本和生成要求脱节。
- 已有视频或可用视频工具时制作动态成片；只有图片时制作动态分镜预演，并注明真实动态未完成。
- 检查广告结构、动作、视觉美学、事实、商品一致性、文字、声音与版本。

示例请求：使用douyin-ad-creative-v0，根据商品图片设计3条不同结构与节奏的抖音广告，输出标准分镜、逐镜视频提示词和测试素材。

本地合成依赖Python3.10+、Pillow、fontTools、FFmpeg和FFprobe。包含字体及许可证。插件通过宿主已配置的视频工具执行生成，不附带视频供应商接口或密钥。当前未接入真实投放与平台报表。

素材生产指令在skills/douyin-ad-creative-v0/SKILL.md；具体结构、数据契约、提示词和检查规则在references/；scripts/提供校验、策划导出、素材合成及版本审查。旧0.1格式仅用于历史复现，新任务使用0.2。
