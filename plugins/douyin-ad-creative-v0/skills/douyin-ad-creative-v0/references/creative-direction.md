# 广告创意、结构与节奏

在生成创意与分镜前读取本文件。以下是本插件的创作预设，可按品牌与任务调整，不是平台标准或投放效果结论。

## 从场景到创意

保留已确认的受众与使用场景。每条创意先写：受众需求、具体时刻、购买障碍、单一核心卖点、可见证据、创意概念、开头悬念、结尾行动。场景必须发生事情，例如“出门前整理领口”，不能只有“咖啡店背景”。

把创意类型和节奏类型分开选择；同一类型可以不同节奏。选择理由应关联购买障碍、证据和现有媒体。用户没有指定数量时通常设计三条；三条至少覆盖两种结构和两种节奏。变化应体现在开头事件、叙事和证据呈现上，不能只换标题、字幕或背景。多要素变化标为探索性比较，不能称单变量 A/B。

## 广告结构类型

| creative_type | 类型 | 阶段顺序 | 适用条件 |
|---|---|---|---|
| problem_solution | 问题解决 | hook → problem → reveal → evidence → cta | 有具体困扰及可展示的解决方式；不夸大痛点或虚构效果 |
| scenario_story | 场景微剧情 | hook → context → reveal → evidence → payoff → cta | 一个人物、一件小事，商品参与动作，结尾回应开头 |
| detail_reveal | 细节揭秘 | hook → reveal → evidence → payoff → cta | 设计、结构或质感有可观察的区别，先提出看点再揭示 |
| styling_montage | 场景搭配蒙太奇 | hook → context → evidence → payoff → cta | 展示用途或搭配变化；只改变搭配，不改变商品 |
| demonstration | 使用演示 | hook → context → action → evidence → cta | 有真实操作或可核对的使用步骤，结论有证据 |

所有阶段都需落到镜头；同一阶段可连续占多镜。开头有可见动作/反差/问题；中段有产品出现和证据；结尾有明确 CTA。视觉卖点可用真实细节展示作为 evidence；虚构体验、生成前后对比、伪消费者口碑不得充当证据。

## 节奏类型限定

| rhythm_type | 节奏 | 建议总时长 | 镜头时长范围 | 节奏设计 |
|---|---|---|---|---|
| punchy | 快节奏冲击 | 10–18秒 | 0.6–3秒 | 首镜动作或细节冲击；中段短镜切换；CTA留约2秒 |
| progressive | 递进种草 | 15–25秒 | 1.5–5秒 | 问题开头、揭示细节、停留看清、行动收尾 |
| narrative | 微剧情节奏 | 20–35秒 | 1.5–6秒 | 建立悬念、人物行动、产品参与、呼应收束 |
| sensory | 舒缓质感 | 15–30秒 | 2–6秒 | 连续动作、柔和运镜，关键细节慢看；避免静态堆图 |

先声明 rhythm_type，再安排每镜时长和 stage。程序检查默认镜长范围；特殊任务可填写 rhythm_override_reason 说明偏离理由，保留创作自由。首镜在约3秒内给出看点，字幕读取与商品细节展示需有停留。不要让所有镜头长度、景别和运动方式都一样。CTA 默认末镜至少1.5秒，特殊节奏注明原因。

## 美术与动态设计

每条创意声明 visual_style：palette（色板）、lighting（主光方向与软硬）、composition（主体和文字位置）、continuity（商品、人物、服饰、地点与轴线连续性）。商品真实颜色不随色板改变。优先选择一种连贯视觉语言，如生活纪录、清透穿搭或干净棚拍，写出具体光线和构图，不堆“高级、电影感、8K”。

每镜给出一个主动作、一个主要运镜和起止状态；环境微动可选。动作应可在镜长内完成，明确方向、速度、幅度与结束姿态。相邻镜头通过动作、视线、形状或声音建立连接。允许固定机位观察主体动作，也允许静止商品配合有目的的运镜；不要求每镜同时移动所有元素。

默认至少60%的计划时长包含主体动作或环境运动，按 subject_action/environment_motion 是否为“无”统计作为策划提醒；真实动态仍需观看验证。产品静物微距可以豁免，但需在 motion_exception_reason 写出创意理由，并保留真实空间变化。图片平移缩放只是预演，不算人物转身、绑带摆动或使用演示。

服装示例：人物从窗边侧身走近→停步轻转肩→领口特写中绑带随动作落下→中景展示完整轮廓。依据原图锁定印花、领口、绑带数量与位置。未经证实的材质、舒适度或显瘦效果不得写成卖点。

## 声音设计

声音写人物对白或旁白，音乐写情绪/节拍/入出点，音响写具体环境声或动作音效及触发时刻；无则明确写“无”。三者分别输出。脚本有声音不代表文件中已有声音。剪辑按动作和音乐重音安排，避免每镜机械加转场声。用户提供或实际生成的完整混音轨才能进入成片；音量与同步需听审。
